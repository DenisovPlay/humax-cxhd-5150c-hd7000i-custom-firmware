## Кросс-прошивка внутри семейства

- **HD 7000i = CXHD-5151 = полный клон CXHD-5150C** (та же плата, тот же CFE,
  тот же формат HDF) [GEMINI; частично НАШЕ — SysID файла HD-7000i отличается
  (805c.8700 vs наш 8050.8400), но наша «оригинальная» перепрошивалась с
  патченным SysID].
- Заявлено: hd_7000i_upgrade.hdf **без правок заголовка** принимается
  CXHD-5150C после простого переименования в cxhd_5150c_upgrade.hdf [GEMINI,
  ПРОВЕРИТЬ — у нас flashed только с патчем SysID].
- Родственный кластер той же ветки ядра: CXHD-5000C (-FI, -TELE2), CXHD-5100C,
  DIGI+C HD, CXHD-5151; Irdeto-родня: IRHD-5100C(/TVT), IRHD-5050C, IHDR-5200C.
  PVR-версия: CHDR (ОнЛайм, 2 тюнера, HDD).
- Доноры утилит/CFW на том же BCM7405: HDR-FOX T2, HD-FOX T2, FOXSAT-HDR.

- USB: FAT32 + MBR [GEMINI; НАШЕ — работало].

## Скрытое сервисное меню (для стока/1.00.48)

- Вход: Меню → Настройки → Система → Информация о системе, затем пультом:
  **Жёлтая → Синяя → Красная → Зелёная → Жёлтая → Синяя → Зелёная → Жёлтая → Синяя**
  [GEMINI; фото пользователя подтверждает существование меню и пункт Fusing Info].
- Функции: выбор оператора (~15 профилей + **None**), Dynamic Update: NO,
  сброс настроек, Fusing Info (S-Boot/S-CW/JTAG/Market/SysID).
- После Operator=None: ручной DVB-C поиск (частота/SR/QAM свободно); часы
  уходят в GMT+0 (EPG сдвинут) — известная особенность.

## Коды ошибок загрузчика (E-xx) — справочник

| Код | Значение |
|---|---|
| E-Id | Invalid System ID |
| E-HF | Invalid HDF Format (нет сигнатуры 0x0012) |
| E-bF / E-Hn | Invalid HDF Version (формат новее лоадера) |
| **E-Ad** | **Invalid Address** — у нас это было на v7 (адрес 0x80001000 = регион CFE) [НАШЕ] |
| E-Ao | Invalid Offset Address For Upload |
| E-AS | Incorrect Application Size |
| E-bC / E-HC | Header Block CRC-16 fail |
| E-dC | Data Block CRC-16 fail |
| E-AC | Application CRC-32 fail |
| E-FE | Failed Compare After Flash Write (verify после записи) |
| E-Fn | Invalid Flash Device (JEDEC не опознан) |
| E-Ft | Flash Program Time Out |
| E-Et / E-It | EEPROM Time Out |
| E-HW | Hardware Error |
| E-OS | Incorrect Operating System (ядро не загрузилось после обновления) |
| E-ut | UART RX/TX Time Out |

Примечание [НАШЕ]: «случайные» ошибки на экране в boot-loop v9d/v9e — это
НЕ коды обновления (обновление завершено), а ошибки стадии ЗАГРУЗКИ; в
справочнике им соответствует разве что E-OS. Быстрое мигание не даёт прочитать код.
