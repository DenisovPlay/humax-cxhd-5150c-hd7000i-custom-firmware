## Общая структура CCX-HDF (model 4, но другая ветка, чем 5100C)

```
[стрим type 0x00] лоадер (если есть)  — относительные адреса 0x0..
[стрим type 0x01] приложение          — относительные адреса 0x0..0x40xxxx
[стрим type 0x03] конфиг/БД           — addr = смещение конфиг-партиции (0x2e0000/0x130000/0xf0000)
[checksum type 0x80] 32B после каждого стрима (или 128B в 2006-м формате)
```
Флаги 0x80 = zlib-кодек humidify (обычный zlib НЕ подходит — кастомный контейнер),
0x00 = сырые данные. humidify 1.0.4 всё распаковывает: `extracted/<имя>/N.hdfbin-type-offset.raw`.

Конфиг-стримы (type 3): бинарная БД — счётчик записей + 16-битные значения; в qnM —
строки регионов (`afr\0afr\0...` = Africa).
