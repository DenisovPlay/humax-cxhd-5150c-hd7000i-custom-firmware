# UART-сессия #1 (2026-10-25): результаты

Железо: CP2102 → /dev/cu.usbserial-0001, логгер uart/uart_log.py (115200, автопереподключение),
лог uart/uart_rx.log, команды — uart/uart_tx.cmd.

## Опознаны на JP650 (4 пина, подпись UART)
- GND: светодиод адаптера горит синим при RXD на пине (линия 0В).
- VCC: красный LED ярче (3.3В через защитный диод).
- Оба средних пина: **никакой реакции ни в логе, ни светодиодом** → пины
  висят в воздухе (не «висят на 3.3В» как живой TX). Вывод: консоль
  физически отрезана (нераспаянные series-резисторы) ИЛИ CFE собран
  немым (pins в high-Z). Различить можно только по разводке (фото) или JTAG.

## BBS (I2C): одиночные «?» — дребезг касания, не данные. I2C ≠ UART, ожидаемо.

## Плата (фото)
- Верх: JP650 + рядом **чёрная 2×4 гребёнка** (8 пинов) — кандидат на
  заводской хедер (возможно JTAG/тест). Пины не опознаны.
- Низ: несколько нераспаянных групп падов (4-пад у надписи HannStar,
  6-пад в правом нижнем углу с маркировкой 1 2) — альтернативные консоли/JTAG?
- DDR2: 2×512Mbit = 128MB ✓ (project_4M_128M). SoC под радиатором = BCM7405.
- У HDR-FOX T2 (тот же SoC) флеш = Micron 32MB NAND → CFE живёт на NAND,
  значит CH341A+SOIC8 (SPI NOR) путь НЕ для нас: NAND параллельный,
  дампить только через EJTAG или дорогой программатор TSOP48.

## Тест «CP2102 в JTAG» — методически пуст
JTAG ≠ UART: TDO молчит без мастера. Консоли оттуда не бывает.

## Следующие шаги
1. Макро-фото: район JP650 сверху и снизу (искать пустые посадки 0603 —
   если есть, закоротить каплей припоя = консоль вернётся).
2. Опознать 2×4 гребёнку и то, во что был воткнут «JTAG» (фото/шелкография).
3. Купить FT232H/FT2232H module (~700–1500₽) → OpenOCD → EJTAG:
   halt CPU, дамп CFE/NAND, поиск ключей шифрования, заливка своего ядра.
   Fusing: JTAG Enable — путь открыт.
4. Параллельно: v9e прошивка (сток-заголовок+патч used_size) — всё ещё не
   проверена на боксе.
