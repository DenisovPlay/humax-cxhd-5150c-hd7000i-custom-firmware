# UART-подключение Humax CXHD-5150C (JP650) — памятка к возвращению домой

Железо: USB-TTL адаптер CP2102 (уже есть), паяльник 60 Вт с медным жалом,
флюс, гребёнка 4 пина PLS (или проводки МГТФ).

## Пайка
1. На плате — площадка **JP650** (4 отверстия, залиты припоем; левая —
   квадратная = pin 1). Она была опознана ещё на старых фото.
2. Распиновка (стандарт Humax/Broadcom, слева направо от pin 1):
   `VCC(3.3V) — RX — TX — GND` (проверить прозвонкой, см. ниже).
3. Отверстия освободить: нагреть + добавить своего припоя (снизить
   температуру плавления заводского бессвинцового), вытолкнуть остатки
   зубочисткой/пином. Впаять гребёнку.
4. Проверка мультиметром (плата ПОД питанием, осторожно):
   - GND: прозвонка на экран/корпус — 0 Ом;
   - VCC: стабильные ~3.3 В — НЕ подключаем к адаптеру никогда;
   - TX: прыгает 0..3.3 В в момент включения (туда смотрим);
   - RX: оставшийся.

## Подключение
- GND адаптера → GND платы.
- RX адаптера → TX платы.
- TX адаптера → RX платы.
- 3V3/5V на адаптере — НИКУДА не подключать.
- macOS: устройство появится как `/dev/cu.usbserial-*` (проверить `ls /dev/cu.*`).

## Терминал на Mac
```bash
screen /dev/cu.usbserial-XXXX 115200,cs8,-parenb,-cstopb
# выход из screen: Ctrl+A затем K
# или: minicom -D /dev/cu.usbserial-XXXX -b 115200
```

## Процедура
1. Открыть терминал, подать питание на приставку.
2. Лог CFE побежит сразу — СОХРАНИТЬ ВСЁ (в screen: Ctrl+A H — лог в файл).
3. В первые ~1-2 сек спамить Space / Ctrl+C — попытка попасть в `CFE>`.
4. Если консоль поймалась, по очереди:
   ```
   help
   printenv            # переменные: ищем OTA-URL, secure/debug флаги
   show devices        # карта flash-партиций (проверка 0x100000/0x300000)
   ifconfig eth0 -addr=192.168.1.99 -mask=255.255.255.0   # (синтаксис по help)
   ```
5. Что нам нужно от лога в первую очередь:
   - строки про проверку образа: «signature», «verify», «secure», «decrypt»;
   - «Uncompressing Linux» — есть/нет;
   - точное имя/адрес партиции ядра;
   - версия CFE и призыв к прерыванию (подсказка «Press any key»).

## TFTP-проба (если консоль есть)
На Mac: `brew install tftp` нет смысла — проще:
```bash
# примитивный TFTP-сервер (udp/69), файл vmlinux в ~/tftp:
python3 -m http.server 8000        # это HTTP — для CFE нужен именно TFTP
# поставить tftpd: brew install tftp... либо sudo launchctl (см. man tftpd)
```
(macOS имеет встроенный tftpd: `sudo launchctl load -F /System/Library/LaunchDaemons/tftp.plist; sudo mkdir -p /private/tftpboot && cp hdf_work/custom_kernel_v8.raw /private/tftpboot/`)
В CFE: `boot -tftp <mac-ip>:custom_kernel_v8.raw` (синтаксис уточнить по help).

## Если UART молчит
- Возможно скорость не 115200 (попробовать 9600/57600/38400).
- Возможно TX/RX перепутаны местами — поменять местами провода.
- Если совсем тишина — консоль отключена в этой сборке CFE → план на EJTAG
  (docs/SECURITY_PATHS.md, путь 2).
