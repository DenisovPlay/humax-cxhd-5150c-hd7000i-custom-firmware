## Если кто-то из них ответит файлом
- Сразу прогнать через `python3 build/hdf_packer.py parse <файл>` — проверить
  SysID (родной должен быть 8050.8400 / диапазон с ним) и сохранить в
  `research_for_other_hdfs/` с помеченным источником.
- Никаких изменений в файл до снятия дампа CFE (JTAG) — родной HDF это
  и есть ключ к подписям: сравнить его 256B-блобы и checksum-блоки с нашими.
