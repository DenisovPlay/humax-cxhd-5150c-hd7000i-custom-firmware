## Шаблон (англ., для Humax)

```
Subject: Recovery firmware request — Humax CXHD-5150C (SysID 8050.8400)

Hello,

I own a Humax CXHD-5150C (OnLime/Rostelecom, DVB-C receiver,
System ID 8050.8400, bootloader Y5.06). The device failed during a
firmware update and no longer boots past the splash screen.

Could you please send me the official firmware/recovery file
(.hdf) for this model so I can restore the device over USB
(CH- + power update procedure)? Alternatively, a pointer to the
official update server would be equally helpful.

Serial: 13110834507683, MAC 08:EB:74:8C:C8:C0.

Thank you very much!
```

## Шаблон (рус., для Ростелеком/OnLime)

```
Тема: Приставка Humax CXHD-5150C не загружается после обновления ПО —
запрос файла прошивки для восстановления

Здравствуйте! Приставка Humax CXHD-5150C (SysID 8050.8400), выданная как
абонентское оборудование OnLиме, перестала загружаться после неудачного
обновления: зависает на экране загрузки. USB-обновление выполняется,
но проблема сохраняется.

Прошу выслать актуальный файл прошивки (.hdf) для восстановления через
USB либо ссылку на сервер обновлений. Серийный номер и MAC предоставлю
по запросу.
```

## Почему это может сработать

- У Humax есть история рассылки recovery-файлов владельцам (форумы
  hummy.tv полны таких случаев для UK-моделей).
- GPL-обязанности уже исполняются (та же страница отдаёт исходники),
  канал связи живой.
- Файл .hdf от оператора = родной шифрованный+подписанный образ:
  единственный гарантированный способ вернуть приставку к жизни
  при включённом Secure Boot — и заодно эталон для изучения формата.
