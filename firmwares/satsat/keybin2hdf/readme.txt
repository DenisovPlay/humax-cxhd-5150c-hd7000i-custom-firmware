Humax satellite receiver emu key file convertert

this wil convert "key.bin" file to "key.hdf" file

1. Unpack this archive in separate folder
2. Get a fresh "key.bin" file from upload server
3. Put "key.bin" into that folder
4. Run MakeKeyHDF.BAT
5. You wil get a file "key.hdf"
6. Download this file to your Humax receiver using WDN4OAK+
